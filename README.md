# 🎬 Film Rental SQL Data Analysis Project

A comprehensive SQL project based on a film rental store database. This project covers database schema setup, data loading, and complex analytical SQL queries to solve business problems.

## 📂 Project Structure
* `schema.sql` - Contains the database tables structure and relationships setup.
* `data.sql` - Contains the sample records and data dumped into the tables.
* `SQL queries.sql` - Contains solutions and SQL queries for 15 business analytical questions.

## 🛠️ How to Use
1. Clone or download this repository.
2. Run `schema.sql` in your MySQL database to create the required tables.
3. Run `data.sql` to populate the database with sample records.
4. Execute `SQL queries.sql` to view the analysis and answers for the 15 questions.

## 🚀 Technologies Used
* MySQL / MySQL Workbench
* SQL (Joins, Subqueries, Views, Window Functions, Aggregations)
